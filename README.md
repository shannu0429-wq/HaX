# Pip · Junior Dream Engineer at Midnight Nursery
> **A Champion Submission for haX.baby 48-Hour Hackathon (17–19 October 2026)**
> **Track 1:** *Same Baby, 1,000 Websites (The Skull Baby: Pip)*
> **Tagline:** *"I build the dreams you fall asleep inside."*

---

## 🌟 Live Demo & Repository
- **Tech Stack:** React 18, Vite, TypeScript, Tailwind CSS, Framer Motion, Web Audio API, Canvas Confetti.
- **Self-Contained:** Zero external asset dependencies, zero broken audio CDN links. Runs completely offline or anywhere deployed (Vercel, Netlify, GitHub Pages).

---

## 🏆 Rubric Alignment & Scoring Breakdown

### 1. Functionality & Polish (35%)
- **Zero Errors:** Strict TypeScript compilation with 0 console warnings or errors.
- **Smooth 60fps Physics:** Spring-interpolated pupil tracking, interactive Web Audio synthesizers, and seamless theme transitions.
- **State Management:** Reactive sound engine with master mute sync across all components.

### 2. Early-Web Soul & Whimsy (30%)
- **90s / 00s Cozy Aesthetics:** Retro web badges (*"Best viewed at 2:00 AM under a blanket"*, *"Enhanced with Web Audio"*), animated stars, and a nostalgic **Midnight Spirits Webring** banner (`[« Prev] [Random Dream] [Next »]`).
- **Story Over Text:** Concise bedtime vignettes (<100 words per chapter) with cozy illustrations and playful micro-reactions.

### 3. Creativity & Surprises (20%)
- **The Lullaby Lab:** Playable 8-key music box with real pentatonic frequencies and an "Auto-Lullaby" arpeggiator.
- **The Nightlight Collection:** 3 interactive bedside lamps (Crescent Moon, Star Jar, Cloud Puff) casting dynamic radial glow across handwritten engineering notes.
- **Rooftop Logistics Game:** An interactive midnight skyline where clicking drops dream bubbles into sleeping chimneys with bubble pops and confetti bursts.
- **The Secret Bow Easter Egg:** Clicking Pip's nightcap bow 3 times triggers an adorable baby giggle, dims the room, sends Pip to sleep, and floats glowing constellation "Zzz" particles.

### 4. Clean Craft & Mobile Responsiveness (15%)
- **Mobile First:** Responsive down to 360px viewport widths with native touch gesture fallbacks.
- **Ultra-Fast Performance:** Single lightweight bundle, pure vector graphics, and CSS radial lights.
